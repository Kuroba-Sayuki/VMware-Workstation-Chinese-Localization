## 文件说明
- 语言文件提取自`VMware-Workstation-Full-17.6.4-24832109`版本。
- VMware Tools的**中文语言文件**包含：`zh_CN`「简体中文」、`zh_TW`「繁体中文」
- VMware VGAuth的**中文语言文件**包含：`zh_CN`「简体中文」、`zh_TW`「繁体中文」
- VMware Workstation的**中文语言文件**包含：`zh_CN`「简体中文」

## 使用方法

> ⚠️ 仅有`VMware Workstation`的使用说明，选择一个你喜欢的方案使用即可。

### 前期准备
- 将本仓库**下方路径内的文件夹**下载到本地。
  - `VMware Workstation Messages/zh_CN`
- 将**zh_CN**文件夹，放到**VMware Workstation Pro安装路径**内的**messages文件夹**中。
```
Your path/messages
```
- **zh_CN文件夹**内，**含下方**文件：
  - `vmappsdk-zh_CN.dll`
  - `vmui-zh_CN.dll`
  - `vmware.vmsg`
- **使用前，一定要确保，下载的文件是完整的。**

### 方案一

> 📖 VMware用户配置文件修改方案

- 进入`%APPDATA%\VMware`配置目录。
- 编辑`preferences.ini`配置文件。
- 在配置文件内，插入下方内容：
```
pref.locale = "zh_CN"
```
- 保存配置文件，打开VMware查看效果。

### 方案二

> 📖 快捷方式添加启动参数方案

- 右键VMware快捷方式，点击属性。
- 在弹出的属性窗口内，找到快捷方式选项卡。
- 在**目标**位置处，**引号尾部空一格**后，添加下方内容：
```
--locale zh_CN
```
- 目标位置处，正确格式如下：
```
"Your path" --locale zh_CN
```

### 方案三

> 📖 快捷方式添加启动参数方案

- 右键VMware快捷方式，点击属性。
- 在弹出的属性窗口内，找到快捷方式选项卡。
- 在**目标**位置处，**引号尾部空一格**后，添加下方内容：
```
--locale zh_CN.
```
- 目标位置处，正确格式如下：
```
"Your path" --locale zh_CN.
```

### 首页对比
- **方案一**：
  - VMware**首页标题**会显示：**Workstation Pro 17**
- **方案二**：
  - VMware**首页标题**会显示：**Workstation Pro 17**
- **方案三**：
  - VMware**首页标题**会显示：**Workstation Pro 25H2**
- **方案二**与**方案三**的唯一区别：
  - 方案三的启动参数，尾部多加了一个`.`。
  - 也许后续版本号，也可以通过这样的方式来显示，如：26H1、26H2...
- **目前尚不明确，多加的这一个**`.`**，是否会存在其它影响，请酌情使用。**

## 方案原理
- 将**旧版本**的语言文件，导入到**新版本**的语言文件目录中，供VMware调用。
- 通过修改**VMware用户配置文件**或**快捷方式添加启动参数**的方式。
- 让VMware在启动时，调用指定的语言文件，进行最终的界面语言显示。

## 注意事项
- **切记**，这是一个**旧版本「`17.6.4`」语言文件**，导入到**新版本**中使用的**过渡**方案。
- 这意味着：
  - **新增功能将无翻译**：如果**Broadcom**在后续版本中增加了新特性、新选项或新界面，这些**新增内容将没有对应的中文翻译**，会显示为软件的默认语言。
  - **翻译内容非最新版本**：本仓库内看到的翻译文本，反映的是`17.6.4`版本时的界面状态，可能与新版界面的**上下文存在细微**出入。
- **若无法接受这两点，请放弃此方案。**
- 最后，希望**Broadcom**能在后续版本中，尽快添加回**被移除的多国语言**支持。
